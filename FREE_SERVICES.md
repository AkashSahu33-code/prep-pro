# Free Services Used

## LLM
- **Google Gemini API** (gemini-1.5-flash) - Free tier: 15 RPM, 1M TPM, 1500 req/day
  Get key: https://aistudio.google.com/app/apikey

## YouTube Transcript
- **youtube-transcript** npm package - Free, no API key needed

## Text to Speech (Hindi/Hinglish)
- **Web Speech API** - Browser built-in, free

## Search / RAG grounding
- **DuckDuckGo Instant Answer API** - Free, no key needed
  https://api.duckduckgo.com/?q=query&format=json

## Spaced Repetition
- SM-2 algorithm implemented locally (no API)

## Storage
- localStorage (browser) - no backend needed

## Setup
Create .env.local:
GEMINI_API_KEY=your_key_here
